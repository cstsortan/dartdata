# Specification: Flutter Provider Integration

**Track ID:** flutter-providers_20260405
**Type:** Feature
**Created:** 2026-04-05
**Status:** Draft

## Summary

Implement `ModelContainerProvider` (InheritedWidget) and `ModelContext.of(BuildContext)` so that the container and context are accessible throughout the Flutter widget tree without manual passing.

## Context

The API design document shows `ModelContainerProvider` wrapping the app in `main()` and `ModelContext.of(context)` being used in widgets to access the context. Neither is implemented yet. This is the glue that makes dartdata feel native in Flutter apps.

## User Story

As a Flutter developer, I want to wrap my app in `ModelContainerProvider(container: ...)` and access the context anywhere via `ModelContext.of(context)`, so that I don't have to thread the container through every widget constructor.

## Acceptance Criteria

- [ ] `ModelContainerProvider` is an `InheritedWidget` that holds a `ModelContainer`
- [ ] `ModelContainerProvider.of(BuildContext)` returns the nearest container
- [ ] `ModelContext.of(BuildContext)` creates/retrieves a `ModelContext` from the nearest provider
- [ ] Throws a descriptive error if no provider is found in the widget tree
- [ ] `ModelContainer.dispose()` cleans up the database connection
- [ ] Widget tests verify the full provider → context → query flow

## Dependencies

- Existing: `ModelContainer`, `ModelContext`
- Blocks: Track H (`QueryObserver`) can use `.of(context)` for context access

## Out of Scope

- Scoped contexts (multiple contexts per screen)
- Context pooling or caching
- Provider for third-party state management (Riverpod, Bloc, etc.)

## Technical Notes

- `ModelContainerProvider` extends `InheritedWidget`
- `updateShouldNotify`: return `old.container != container` (reference equality)
- `ModelContext.of(BuildContext)`: look up `ModelContainerProvider`, create `ModelContext(container)`
- Consider: should `ModelContext.of()` cache the context per widget? Probably not — contexts are lightweight and short-lived
- Place widget code in `dartdata/lib/src/widgets/` alongside `QueryObserver`
- Export from `dartdata.dart` barrel file
