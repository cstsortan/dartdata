## Summary

Build a pure-Dart `dartdata_example` package that exercises every dartdata feature (annotations, generator, runtime) against a real SQLite database, runnable with `dart test` — no Flutter engine or simulator required.

## Context

dartdata is a Flutter persistence library inspired by SwiftData. The core library (`dartdata/`) and code generator (`dartdata_generator/`) are tested with hand-written model stubs via `flutter test`. This track adds a third package (`dartdata_example/`) that uses real `@model`-annotated classes run through the generator, verifying the full stack end-to-end.

## User Story

As a dartdata contributor, I want an end-to-end integration test suite so that I can verify the full library stack (annotations, generator, runtime) works correctly against a real SQLite database.
