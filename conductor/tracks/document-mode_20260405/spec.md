# Specification: Document Mode

**Track ID:** document-mode_20260405
**Type:** Feature
**Created:** 2026-04-05
**Status:** Draft

## Summary

Fully implement `ModelConfiguration.document(directory:)` so that the database and all blob files are co-located in a single directory package, mirroring SwiftData's document-based app support.

## Context

`ModelConfiguration.document()` exists as a factory constructor but is not fully implemented. The API design document specifies a directory layout where `StoreContent` (the SQLite database), WAL files, and blob files all live inside a single user-facing directory. This enables portable documents that can be copied, shared, or archived as a single unit.

## User Story

As a developer building a document-based app (e.g., a presentation editor), I want all data and assets for a document to live in one directory, so I can move, copy, or share it as a single portable unit.

## Acceptance Criteria

- [ ] `ModelConfiguration.document(directory: dir)` creates the directory if it doesn't exist
- [ ] Database file is named `StoreContent` inside the directory
- [ ] Blob files live in `<dir>/blobs/<ModelType>/<id>/` (or `<dir>/_EXTERNAL_DATA/`)
- [ ] WAL files (`StoreContent-shm`, `StoreContent-wal`) are co-located
- [ ] A document container can be created, populated, closed, and reopened with data intact
- [ ] Copying the directory to a new location and opening it there works

## Dependencies

- Existing: `ModelConfiguration.document()` factory constructor
- Existing: `ModelContainer._blobDirectory()` logic
- Existing: blob storage and ExternalFile persistence

## Out of Scope

- Zip/archive of documents
- File-level encryption
- macOS/iOS document picker integration
- Concurrent access to the same document from multiple processes

## Technical Notes

- Database path: `<directory>/StoreContent`
- Blob path: `<directory>/_EXTERNAL_DATA/` (flat UUID layout, consistent with standard mode)
- On `create()`: ensure `directory.createSync(recursive: true)` before opening DB
- On `dispose()`: checkpoint WAL (`PRAGMA wal_checkpoint(TRUNCATE)`) for a clean document
